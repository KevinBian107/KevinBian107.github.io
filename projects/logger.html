📅 Project Timeline: Feb 2026 - Now
Website Code

A free, local-first productivity app that bridges the gap between planning and execution. Block out your days with drag-to-create time blocks and priority flagging, start the timer the moment you begin, and let year-at-a-glance dashboards, streaks, and a Claude-powered AI you can ask turn every logged minute into a clear picture of how you actually spend your time. Everything lives in a single local SQLite file — no account, no server, no data leaving your machine.

log(ger) — plan it, track it, understand it.

log(ger) evolved from an earlier project — a personalized numerical and text database built in Python/Jupyter for tracking study data at UCSD. That original project examined different study habits through vectorized data storage and analysis workflows, and served as the foundation for this full-stack rebuild.
